# 庭前复核 Skills 完整套件

面向中国大陆民商事与行政诉讼承办律师的 Codex Skill 套件。包含庭前复核主 Skill 与 15 个按争点选用的法律方法 Skill。

## 下载与安装

下载本仓库的 [`庭前复核Skill-完整套件.zip`](庭前复核Skill-完整套件.zip)，解压后将其中 `skills/` 下的 16 个文件夹复制到自己的 `~/.codex/skills/`（或实际配置的 `$CODEX_HOME/skills/`），再开启新的 Codex 会话。参见 [安装说明](安装说明.md)。

压缩包内保留每个 Skill 的 `SKILL.md`、参考文件、脚本和目录结构；仓库根目录的 `文件清单.sha256` 可核对内容。

本套件不包含法宝 MCP、账号、Token、数据库内容或案件卷宗。法条和案例的真实检索仍需使用者在自己的环境中完成；无法核验全文或效力时，Skill 会要求说明限制。
